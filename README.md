# COMP2S01

All coursework for COMP2S01, one folder per piece of work.

| Folder | What it is |
|---|---|
| [`hw1-momo/`](hw1-momo/) | Assignment 1: *Momo Learns to Munch*, an educational AI game for Grade 5/6 pupils, plus its intro video. |
| [`inclass1-math-meteor-defense/`](inclass1-math-meteor-defense/) | In-class assignment: *Math Meteor Defense*, a single-file HTML mini-game for Grade 5/6 pupils, with its first version (MVP) kept beside it. |

## Versions

Milestones are marked with git tags named `<folder-prefix>-v<version>`:

| Tag | What it is |
|---|---|
| `hw1-v0` | Momo, first implementation |
| `hw1-v0.1` | Momo, hand-made picture-book redesign |
| `inclass1-v1` | Math Meteor Defense V1, the polished game (the MVP stays in the tree as `math-meteor-defense-mvp.html`) |
| `inclass1-v1.1` | Math Meteor Defense V1.1, hints for wrong answers |

To look at an old version: `git checkout hw1-v0` (and `git checkout main` to come back).
